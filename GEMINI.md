## 🔁 SIKLUS HIDUP LENGKAP VIBE CODING MATURE (0–100 PRODUCTION PIPELINE)

Setiap pengembangan fitur, perbaikan bug, atau refactoring kode WAJIB mengikuti 10 fase otomatis berikut tanpa ada tahap yang dilewati:

### 0. Tahap Pemetaan Pengetahuan & Konteks Kode (Codebase Graph & Context)
- **`graphify`**: Sebelum memodifikasi kode kompleks, petakan relasi AST dan dependensi antar file menjadi knowledge graph untuk mencegah efek samping (side-effects) dan mengidentifikasi *god nodes*.
- **`graphrag`**: Ekstraksi dan query konteks arsitektural lintas dokumen secara komprehensif (Global & Local search).
- **`mem0-context-memory-manager`**: Simpan dan patuhi seluruh keputusan arsitektural masa lalu, preferensi tech-stack, invariant skema, dan pelajaran dari bug terdahulu.

### 1. Tahap Perancangan & Autonomous PRD (Planning & Task Graph)
- **`prd-taskmaster`**: Ubah ide atau permintaan user menjadi task-graph deterministik dengan pemetaan dependensi yang ketat antar modul.
- **`ralph`**: Terapkan loop eksekusi otonom PRD berbasis spesifikasi terukur hingga seluruh pengujian 100% hijau.
- **`prd-blueprint-architect` & `spec-kit`**: Validasi spesifikasi formal, alur data, ERD database, dan kontrak API sebelum menulis baris kode pertama.
- **`agent-orchestrator-delegator`**: Delegasikan pekerjaan multi-bidang secara terisolasi (Frontend, Backend, Database/Ledger, Security, QA).

### 2. Tahap Arsitektur Domain & Kontrak API (API & Domain Architecture)
- **`akaunting`**: Terapkan standar akuntansi enterprise: double-entry bookkeeping (`SUM(debit) == SUM(credit)`), isolasi multi-tenant, presisi desimal non-float untuk nilai moneter, dan mutasi saldo hanya melalui jurnal transaksi/reversal.
- **`trpc-architecture`**: Gunakan end-to-end typesafe API contract tanpa codegen antara frontend dan backend; validasi seluruh input dengan schema runtime (Zod/Valibot).
- **`fullstack-platform-architect`**: Arsitektur produksi teruji: Cloudflare Workers/Pages, Supabase (PostgreSQL RLS), IndexedDB offline-first sync (Conflict-Free), dan PWA mobile-ready.

### 3. Tahap Eksekusi Vibe Coding (Implementation & Aesthetics)
- **`vibe-coding-engineer`**: Tulis kode matang, modular, idiomatik, efisien, dan patuh prinsip YAGNI (Deletion before addition, native platform API over unnecessary dependencies).
- **`ui-ux-design-system`**: Tampilan visual WAJIB memukau (Rich Aesthetics: dark mode elegan, glassmorphism, curated HSL/OKLCH colors, micro-animations, transisi halus, responsive lintas viewport Desktop & HP, zero default colors).

### 4. Tahap Anti-Error & Integritas (Zero Hallucination & Zero Dummy)
- **`anti-hallucination-verifier`**: DILARANG mengimpor package/modul khayalan. Semua dependensi WAJIB terdaftar sah di `package.json` atau stdlib.
- **`production-code-enforcer`**: DILARANG keras meninggalkan `TODO`, `FIXME`, `mock`, `dummy`, `placeholder`, atau fungsi kosong `{}`. Setiap baris kode WAJIB fungsional nyata.
- **`bug-hunter-debugger` & `systematic-debugging`**: Investigasi akar masalah (root cause) berbasis log dan stack trace empiris. DILARANG mematikan error dengan `try {} catch (e) {}` senyap tanpa penanganan data integrity.

### 5. Tahap Audit Keamanan & Red-Team (DevSecOps)
- **`claude-bughunter` (83 Hunting Skills)**: Audit mendalam sebelum rilis:
  - `hunt-auth-bypass` & `hunt-jwt-crypto`: Verifikasi algoritma JWT, otentikasi API, dan proteksi sesi.
  - `hunt-idor`: Validasi kepemilikan data pada setiap query/mutasi (zero unauthenticated object access).
  - `hunt-business-logic` & `hunt-race-condition`: Cegah manipulasi harga/saldo, double-spending, dan kupon race condition.
  - `hunt-sqli`, `hunt-ssrf`, `hunt-xss`, `hunt-csrf`: Sanitasi ketat batas input & output.
- **`semgrep-code-audit`**: Static Application Security Testing (SAST) otomatis pada workspace.
- **`gitleaks-secret-scanner`**: DILARANG keras menyimpan hardcoded token, API key, JWT secret, atau private key di repositori.

### 6. Tahap Linter & Pemformatan Instan (Biome Rust Engine)
- **`biome-linter`**: Jalankan toolchain Rust Biome (`biome check --write`) untuk pemformatan instan, pengurutan impor, dan linting berkecepatan tinggi dengan standar 0 warning.

### 7. Tahap Pengujian Otomatis & E2E (Testing & Benchmarking)
- **`vitest-runner`**: Jalankan unit test & integration test berbasis native Vite dengan coverage mendalam pada fungsi inti (ledger, auth, kalkulasi transaksi).
- **`playwright-e2e`**: Jalankan pengujian otomatis end-to-end pada browser nyata (Desktop dan Mobile viewports) untuk memastikan sinkronisasi data antar device berjalan real-time tanpa anomali.
- **`automated-testing-benchmark-comparator`**: Dokumentasikan tabel komparasi Sebelum vs Sesudah (kecepatan, bundle size, penggunaan memori).

### 8. Tahap Finishing, Core Web Vitals & Production QA Gate
- **`performance-seo-finishing-polisher`**: Optimasi Core Web Vitals (LCP, CLS sub-0.1, INP), asset treeshaking, dynamic SEO/OpenGraph, dan aksesibilitas WCAG AA.
- **`pre-commit-qa-gate`**: Lakukan verifikasi build kompilasi bersih dan linting tanpa warning sebelum perubahan dinyatakan selesai.
- **`verification-before-completion`**: DILARANG menyatakan tugas selesai tanpa bukti eksekusi perintah verifikasi yang valid.

### 9. Tahap Audit Trail & Laporan (Reporting & Triage)
- **`report-writing` & `triage-validation`**: Sajikan ringkasan perubahan, hasil pengujian empiris, langkah reproduksi, dan mitigasi risiko secara jelas, terstruktur, dan terverifikasi.
